# Electromagnetic Spectrum Figure

This repository contains:

- `spectre_em.py` — Python script to generate a figure of the electromagnetic spectrum.
- `spectre_em.pdf` — Figure showing the electromagnetic spectrum, highlighting the thermal radiation region.
- `spectre_em.png` — Figure showing the electromagnetic spectrum, highlighting the thermal radiation region.
- french version of the previous figures
